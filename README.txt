Climate Policy Assistant - run locally (voice input works here)

1. Open a terminal in this folder.
2. Run:  python3 -m http.server 8000
3. Open http://localhost:8000 in Chrome or Edge.
4. Click the microphone, allow access, and speak your question.

Notes
- Voice input needs Chrome/Edge (or Safari) and an internet connection (the browser sends audio to its speech service).
- Locally, answers are search-only quotes from the documents. The Claude-written summaries work only in the shared artifact page.
